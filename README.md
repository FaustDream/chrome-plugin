# 开发助手

Chrome/Edge 浏览器扩展（Manifest V3），为云枢（CloudPivot）与氚云（H3Yun）两个低代码平台的在线开发页面提供本地代码抓取、回写与目录协作。

- 版本：2.0.5
- 作者：凌致

## 功能

- **云枢**：抓取 / 回写前端 HTML/CSS/JS、业务规则（Java）、FromCode.md；按需生成 README/AGENTS/DESIGN 协作文件
- **氚云**：一键抓取（FromCode + 前端 JS + 后端 C#）与一键回写，表单 / 列表双模式
- **目录管理**：File System Access API 本地目录绑定，按页面业务实例记忆、页面间互不串用；新页面需手动选择（选择器优先定位到设置页默认目录）；历史目录搜索一键恢复，跨标签页同步
